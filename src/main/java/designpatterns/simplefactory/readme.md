<h1>Simple Factory Pattern</h1>
A factory pattern is a type of pattern where objects can be created without having to worry about exposing the object creation logic to the client. In a simple factory pattern, <b><u>one factory</b></u> decides which concrete object to create. 
<br><br>
<b><i>Note to self: For simplicity, Main class can be treated as a client.</i></b>
